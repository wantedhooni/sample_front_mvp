# LeadForge 작업 지침

## 프로젝트 개요
- 프로젝트명: LeadForge
- 목표: 브랜드 홈페이지와 문의 리드 수집 기능을 결합한 SaaS MVP 구현
- 기술 스택: Next.js, React, Tailwind CSS

## 작업 원칙
- 실무 관점에서 바로 시연 가능한 수준으로 구현한다.
- 랜딩, 기능 소개, 가격, 문의 폼, 블로그 화면을 포함한다.
- 문서와 스크립트는 유지보수 가능하도록 단순하고 명확하게 작성한다.
- 불필요한 외부 의존성은 최소화한다.

## 구현 원칙
- 반응형 UI를 기본으로 설계한다.
- 문의 유도와 전환 흐름이 자연스럽게 이어지도록 구성한다.
- 더미 데이터와 문구도 실제 SaaS 서비스처럼 작성한다.
- 코드 구조는 추후 API, 인증, CMS 연동이 가능한 형태로 정리한다.

## 문서 원칙
- 작업 계획과 작업 내역은 한글로 관리한다.
- README에는 실행 방법, 주요 화면, 테스트 방법을 최신 상태로 유지한다.

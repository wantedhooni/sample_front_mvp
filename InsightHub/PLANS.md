# InsightHub 작업 계획

## 1. 초기 세팅
- Next.js 앱을 생성하고 Tailwind 기반 UI 환경을 준비한다.
- 기본 디렉터리 구조와 공통 데이터 모델을 정리한다.

## 2. 핵심 화면 구현
- 랜딩 페이지에서 서비스 가치, 추천 콘텐츠, 구독 유도 섹션을 구성한다.
- 카테고리, 아티클 상세, 북마크, 구독 결제 페이지를 구현한다.

## 3. 사용성 보강
- 공통 헤더, 탐색 구조, 카드, 배지, CTA를 정리한다.
- 반응형 레이아웃과 기본 접근성을 점검한다.

## 4. 운영 문서 정리
- 실행 스크립트를 작성한다.
- README와 TASK 문서를 최신 상태로 업데이트한다.

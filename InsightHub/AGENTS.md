# InsightHub 작업 지침

## 프로젝트 목표
- 구독형 리서치/뉴스 서비스 `InsightHub`의 프론트 MVP를 구현한다.
- 검색 유입, 콘텐츠 탐색, 회원가입, 유료 전환 흐름이 자연스럽게 이어지도록 설계한다.

## 작업 원칙
- Next.js, React, Tailwind CSS 기준으로 구현한다.
- 실무 서비스처럼 정보 구조, 상태 흐름, 컴포넌트 분리를 명확하게 유지한다.
- 문서는 한글로 작성하고, 변경 사항은 `TASK.md`에 기록한다.
- README는 실행 방법과 데모 흐름이 바로 보이도록 유지한다.

## 구현 범위
- 랜딩 페이지
- 카테고리 탐색 페이지
- 아티클 상세 페이지
- 북마크 화면
- 구독 결제 화면

## 산출물 원칙
- 디자인은 콘텐츠 서비스 성격이 드러나도록 차분하지만 밀도 있게 구성한다.
- 더미 데이터라도 실제 서비스 데모가 가능한 수준으로 작성한다.
- 프로젝트 단위 실행 스크립트는 `scripts` 디렉터리에서 관리한다.
